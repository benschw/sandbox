# sandbox

## Books

The books page (`books/index.html`) is built from JSON files in `books/data/`, which are generated by the scripts in `books/scripts/`. Everything runs locally through `make`; pushing to `main` deploys the site to GitHub Pages (`.github/workflows/static.yml`).

### Prerequisites

- Python 3 (no third-party packages required)

### Updating your read list

> **Reminder:** Goodreads retired its shelf RSS feeds, so the read list only updates
> when you export your library and rebuild. Do this after finishing a book.

1. On goodreads.com, click **My Books** in the top nav.
2. In the left sidebar, under **Tools**, click **Import and export**
   (or go straight to <https://www.goodreads.com/review/import>).
3. Click **Export Library** at the top of the page. Generating the file can take a
   minute; when it's ready, a **Your export from &lt;date&gt;** link appears below the button.
4. Download it and save it over `books/data/goodreads_library_export.csv`.
5. Run `make all` from the repo root.
6. Commit the export and the updated `books/data/` files, and push to `main` to deploy.

Covers and links for books already in `books.json` are kept; new books get a cover from Open Library by ISBN, or a placeholder if none is found. Placeholders are retried the next time you run `make books`.

### Make targets

| Target | Runs |
|---|---|
| `make books` | `fetch_books.py` — build `books.json` from the Goodreads export |
| `make series` | `sync_all_series.py` — re-scrape every series in the index from Goodreads |
| `make unread` | `sync_unread_series_books.py` — regenerate `series_unread.json` |
| `make all` | all three, in that order |

`make series` fetches each series sequentially with a 2 s delay between requests, so it takes a while. It's also useful on its own after Goodreads updates publication dates or after changes to the scraping logic.

### Adding a new series

Find the series page on Goodreads (e.g. `goodreads.com/series/49075-the-locked-tomb`) and run:

```sh
make books  # refresh read list from the export first
python books/scripts/add_series.py https://www.goodreads.com/series/49075-the-locked-tomb
```

`add_series.py` scrapes the series page, upserts it into `goodreads_series_index.json`, and regenerates `series_unread.json`. Commit the updated data files to deploy.

### Data files

| File | Written by | Contents |
|---|---|---|
| `books/data/goodreads_library_export.csv` | you (Goodreads export) | Full Goodreads library — the source of truth |
| `books/data/books.json` | `make books` | Read shelf + currently-reading shelf, built from the export |
| `books/data/goodreads_series_index.json` | `make series` / `add_series.py` | Series metadata and book lists scraped from Goodreads |
| `books/data/series_unread.json` | `make unread` / `add_series.py` | Series books not yet on your read shelf |
| `books/data/ignore.json` | manual | Titles to exclude from series views (e.g. companion novellas) |
